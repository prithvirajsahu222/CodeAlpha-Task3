# CodeAlpha Task 3 – Supermarket Sales Data Visualization

## Objective
Analyze and communicate supermarket sales data using meaningful visualizations.

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Visualizations
- Category-wise sales
- Monthly sales trend
- City-wise sales
- Payment method distribution
- Category-wise profit
- Sales vs profit
- Quantity vs sales
- Correlation heatmap
- Monthly sales and profit comparison
